# Ubuntu VPS Bootstrap

Интерактивный Bash-скрипт для базовой и безопасной настройки нового VPS под
управлением Ubuntu.

Bootstrap подготавливает сервер к дальнейшей установке VPN или других сервисов:
создаёт отдельного администратора, настраивает доступ по SSH-ключу, переносит
SSH на выбранный порт, включает firewall, Fail2ban и BBR, а затем проверяет
фактически применённые настройки.

> [!IMPORTANT]
> Скрипт изменяет параметры удалённого доступа. Не закрывайте текущую SSH-сессию,
> пока не проверите новое подключение в отдельной вкладке Termius или другого
> SSH-клиента.

## Требования

- чистый VPS с Ubuntu (рекомендуется 24.04 LTS);
- доступ к серверу под `root`;
- рабочее интернет-соединение на сервере;
- заранее созданная пара SSH-ключей;
- открытая часть SSH-ключа одной строкой.

Приватный SSH-ключ вводить в Bootstrap нельзя. Он должен оставаться только на
устройстве пользователя.

Рекомендуемая версия — Ubuntu 24.04 LTS. На других версиях Ubuntu скрипт
показывает предупреждение и предлагает продолжить только после явного
подтверждения; совместимость не гарантируется. Enter отменяет запуск до изменения
настроек. Другие дистрибутивы не поддерживаются.

Публичный скрипт прошёл статическую проверку. Полноценное тестирование на VPS
пока не завершено.

## Запрашиваемые параметры

| Параметр | Описание |
|---|---|
| Hostname | Имя сервера. По умолчанию предлагается текущее имя. Допускается короткое имя или полноценное доменное имя без автоматического обрезания. |
| Имя пользователя | Имя нового администратора без входа под `root`. Значение по умолчанию — `vpnadmin`. |
| Открытый SSH-ключ | Публичная часть ключа, например `ssh-ed25519 ...`. Формат и fingerprint проверяются до изменения SSH. Приватные ключи отклоняются. |
| SSH-порт | При первом запуске предлагается случайный свободный непривилегированный порт. Можно нажать Enter или указать собственный порт от `1024` до `65535`. Один и тот же порт применяется в SSH, UFW и Fail2ban. |
| Часовой пояс | Значение по умолчанию — `Europe/Moscow`. Можно указать другую зону из базы IANA, например `Europe/Minsk`, `UTC` или `Europe/Berlin`. |
| Подтверждение | Перед изменениями показывается итоговая конфигурация. Установка начинается только после явного подтверждения; ответ по умолчанию — `No`. |

## Что настраивает Bootstrap

| Компонент | Изменения |
|---|---|
| Проверка системы | Проверяет запуск от `root`, Ubuntu, необходимые системные команды и корректность введённых значений. На других версиях Ubuntu показывает предупреждение и запрашивает отдельное подтверждение. |
| Hostname | Устанавливает выбранное имя, синхронизирует `/etc/hostname` и `/etc/hosts`, удаляет старые локальные имена и дубли, сохраняя localhost, IPv6, комментарии и посторонние записи. |
| Cloud-init | Запрещает cloud-init позднее заменять выбранный hostname или перегенерировать `/etc/hosts`. Остальные функции cloud-init не отключаются. |
| Пользователь | Создаёт отдельного администратора, добавляет его в группу `sudo`, блокирует пароль и настраивает `sudo` без запроса пароля. |
| SSH-ключ | Записывает только введённый открытый ключ в `.ssh/authorized_keys` и устанавливает безопасные права на каталог и файл. |
| Пакеты | Обновляет список пакетов и устанавливает OpenSSH Server, UFW, Fail2ban и `iproute2`. Пакет `iproute2` предоставляет команды `ip` и `ss`, необходимые для проверки сети и фактически открытого SSH-порта. |
| SSH | Применяет выбранный порт, запрещает вход под `root`, парольную и keyboard-interactive-аутентификацию, оставляя только вход по SSH-ключу. |
| Конфликты SSH | Удаляет конфликтующие параметры из основного конфига и drop-in-файлов SSH, включая настройки образа или cloud-init. Посторонние параметры и комментарии сохраняются. |
| Проверка SSH | Проверяет синтаксис через `sshd -t`, анализирует итоговые параметры через `sshd -T` и после перезапуска проверяет фактически слушающий порт через `ss`. |
| Socket activation | При необходимости отключает `ssh.socket` и включает обычную службу SSH, чтобы выбранный порт применялся однозначно. |
| UFW | Запрещает входящие соединения по умолчанию, разрешает исходящие и открывает только выбранный SSH-порт. Старое стандартное правило SSH удаляется после подготовки нового порта. |
| Fail2ban | Включает защиту SSH от повторяющихся неудачных попыток входа и привязывает её к выбранному SSH-порту. |
| BBR | Включает TCP BBR и очередь `fq` для более эффективного управления сетевым трафиком. |
| Часовой пояс | Устанавливает выбранную зону через `timedatectl` после проверки её наличия в системе. |
| Откат | Перед критическими изменениями создаёт временную резервную копию SSH, UFW и Fail2ban. При ошибке возвращает исходную конфигурацию. |
| Аудит | Устанавливает команду `sudo vps-bootstrap-audit`, которая ничего не изменяет и показывает фактическое состояние политики SSH. |
| Журнал | Сохраняет полный технический вывод в `/var/log/ubuntu-vps-bootstrap.log` с правами `0600 root:root`. Введённый SSH-ключ в журнал не записывается. |

## Этапы выполнения

На экране отображаются только основные этапы без лишнего вывода пакетного
менеджера и системных служб:

```text
[1/7] Проверка системы
[2/7] Настройка hostname
[3/7] Создание пользователя и установка SSH-ключа
[4/7] Установка системных пакетов
[5/7] Настройка SSH
[6/7] Настройка UFW, Fail2ban, BBR и часового пояса
[7/7] Финальная проверка
```

Полный диагностический вывод остаётся в закрытом системном журнале. Если один из
критических этапов завершится ошибкой, Bootstrap остановится и попытается вернуть
исходную конфигурацию.

## Выбор часового пояса

Для Москвы достаточно нажать Enter при запросе:

```text
Введите часовой пояс [Europe/Moscow]:
```

Для Беларуси можно указать:

```text
Europe/Minsk
```

Посмотреть доступные зоны непосредственно на сервере:

```bash
timedatectl list-timezones
```

Для удобного просмотра по страницам:

```bash
timedatectl list-timezones | less
```

Названия берутся из [официальной базы часовых поясов IANA](https://www.iana.org/time-zones).
Также доступна [таблица идентификаторов часовых поясов](https://en.wikipedia.org/wiki/List_of_tz_database_time_zones).

## Защита от потери доступа

Bootstrap применяет изменения в безопасной последовательности:

1. Проверяет hostname, пользователя, SSH-ключ, порт и часовой пояс.
2. Создаёт пользователя и устанавливает проверенный открытый ключ.
3. Проверяет конфигурацию SSH до перезапуска службы.
4. Открывает новый SSH-порт в UFW до переключения SSH.
5. Перезапускает SSH и проверяет фактически слушающий порт.
6. Проверяет вход только по ключу, состояние UFW и Fail2ban.
7. При ошибке восстанавливает временную резервную копию.

Даже после успешной установки не закрывайте исходную сессию сразу. Сначала
создайте в Termius новое подключение с указанными пользователем и портом и
убедитесь, что SSH-ключ работает.

## Финальный отчёт

После успешной проверки Bootstrap выводит блок, данные из которого нужно
сохранить:

```text
============================================================
✅ Первоначальная настройка VPS успешно завершена

Адрес сервера:     203.0.113.10
Hostname:           vpn-hel-01
Пользователь:       vpnadmin
SSH-порт:           28473
Авторизация:        только SSH-ключ
UFW:                включён
Fail2ban:           работает
BBR:                включён
Часовой пояс:       Europe/Moscow

Сохраните эти данные в надёжном месте.
Не закрывайте текущую сессию, пока не проверите
новое подключение в Termius.
============================================================
```

Если адрес невозможно определить из текущего SSH-подключения, в отчёте будет
указано, что его нужно посмотреть в панели хостинг-провайдера.

## Проверка после установки

Краткий аудит:

```bash
sudo vps-bootstrap-audit
```

Подробный технический отчёт:

```bash
sudo vps-bootstrap-audit --details
```

После проверки нового SSH-подключения рекомендуется перезагрузить VPS и повторно
запустить краткий аудит.

## Что Bootstrap не делает

- не устанавливает VPN;
- не настраивает конкретный VPN-протокол;
- не передаёт SSH-ключи сторонним сервисам;
- не запрашивает приватный SSH-ключ;
- не создаёт пароль для входа;
- не зависит от конкретного хостинг-провайдера;
- не отключает cloud-init целиком;
- не изменяет настройки веб-консоли или rescue-режима провайдера.

Bootstrap выполняет только первоначальную подготовку Ubuntu VPS. Установка VPN
или другого серверного приложения производится отдельным следующим этапом.
